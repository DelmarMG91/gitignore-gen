# gitignore-gen

**Compose production-ready `.gitignore` files from curated, stack-specific templates — in one command.**

[![CI](https://github.com/DelmarMG91/gitignore-gen/actions/workflows/ci.yml/badge.svg)](https://github.com/DelmarMG91/gitignore-gen/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python](https://img.shields.io/badge/python-3.9%2B-blue.svg)](https://www.python.org/)
[![PyPI](https://img.shields.io/badge/pypi-v0.1.0-informational.svg)](https://pypi.org/project/gitignore-gen/)

## Features

- **15 built-in templates** covering Python, Node.js, Go, Rust, Java, C, C++, macOS, Windows, Linux, VS Code, JetBrains, Git, Docker, and Terraform.
- **Smart detection** — `detect` and `init` recognise project markers such as `pyproject.toml`, `package.json`, `go.mod`, `Cargo.toml`, `pom.xml`, `CMakeLists.txt`, and `.terraform/`.
- **Composable merging** — combine any number of templates; duplicate rules are removed while first-seen order is preserved.
- **Non-destructive writes** — existing custom rules are kept, and only missing lines are appended.
- **Dry-run mode** — preview exactly how many lines would be added before touching disk.
- **Zero dependencies** — pure Python standard library, runs anywhere Python 3.9+ runs.
- **Fully tested** — the writer, detector, template registry, and CLI are covered by a pytest suite.


## Quick Start

Generate a `.gitignore` for a Python + Node.js project:

```bash
gitignore-gen add python,node
```

Example output:

```text
Added 52 line(s) to .gitignore
```

The resulting `.gitignore` starts with a provenance header and contains both stacks, with shared rules such as `.env` emitted only once:

```gitignore
# Generated by gitignore-gen

# Byte-compiled / optimized / DLL files
__pycache__/
*.py[cod]
*$py.class

# Distribution / packaging
build/
dist/
wheels/
*.egg-info/
...

# Dependencies
node_modules/
...
```

Prefer to let the tool inspect the directory itself?

```bash
gitignore-gen init .
```

```text
Detected: python, node
Wrote .gitignore (+52 line(s), 61 rule lines)
Header: # Generated by gitignore-gen
```

## Usage

### List templates

```bash
$ gitignore-gen list
python     Python bytecode, virtualenvs, packaging and test caches.
node       Node.js dependencies, build output, logs and env files.
go         Go binaries, test artifacts, workspaces and vendor output.
rust       Rust Cargo target dir, coverage and editor artifacts.
java       Java class files, Maven/Gradle output and IDE metadata.
c          C object files, libraries, executables and build dirs.
cpp        C++ objects, shared/static libs, CMake build trees.
macos      macOS Finder metadata, thumbnails and volume droppings.
windows    Windows thumbnail caches, installer files and shortcuts.
linux      Linux editor swap files, core dumps and trash folders.
vscode     Visual Studio Code workspace state, keeping shared config.
jetbrains  IntelliJ IDEA and JetBrains IDE project metadata.
git        VCS noise: merge/rebase leftovers, patch and local config.
docker     Docker build artifacts, override files and local volumes.
terraform  Terraform state, plans, tfvars secrets and CLI config.

15 templates available.
```

### Show a template

```bash
$ gitignore-gen show rust
# Generated by Cargo
/target/
**/*.rs.bk

# MSVC Windows build artifacts
*.pdb

# IDE / editor
.idea/
.vscode/
*.iml

# OS metadata
.DS_Store
Thumbs.db

# Local environment
.env
.env.*

# Coverage reports
tarpaulin-report.html
lcov.info
```

Unknown names exit with status code `2` and print an actionable error.

### Detect project types

```bash
$ mkdir demo && cd demo
$ touch pyproject.toml app.py package.json
$ gitignore-gen detect .
Detected templates for .:
  python  found Python source files (*.py)
  node    found package.json

Suggested command:
  gitignore-gen add python,node
```

### Merge templates into an existing file

Suppose `.gitignore` already contains your own rules:

```gitignore
# my local rules
coverage-reports/
*.local.json
```

Running `gitignore-gen add python --output .gitignore` keeps both lines and appends only rules that are missing. Running it a second time reports `Added 0 line(s)` — the operation is idempotent.

### Dry run

```bash
$ gitignore-gen add terraform --dry-run
Would add 19 line(s) to .gitignore
Dry run: no files were modified.
```

### Initialise a repository

```bash
$ gitignore-gen init path/to/project
Detected: python, node
Wrote path/to/project/.gitignore (+52 line(s), 61 rule lines)
Header: # Generated by gitignore-gen
```

`init` never overwrites existing content: if a `.gitignore` is present, missing rules are appended and custom lines stay untouched.

## Configuration / Options

| Command | Argument / Option | Default | Description |
| --- | --- | --- | --- |
| `gitignore-gen` | `--version` | – | Print the version (`0.1.0`) and exit. |
| `gitignore-gen` | `--help` | – | Show global help and the command list. |
| `list` | – | – | List every template with a one-line description. |
| `show` | `NAME` | – | Print one template to stdout. Unknown name exits `2`. |
| `detect` | `[PATH]` | `.` | Scan a directory and print detected templates plus a suggested `add` command. |
| `add` | `NAME[,NAME...]` | – | One or more template names. Comma-separated and repeated values are accepted. |
| `add` | `--output`, `-o` | `.gitignore` | Destination file. |
| `add` | `--dry-run` | off | Report how many lines would be added without writing. |
| `init` | `[PATH]` | `.` | Detect the project type and write `PATH/.gitignore`. |

Exit codes: `0` success, `2` usage error or unknown template.

## Templates

| Name | Covers |
| --- | --- |
| `python` | `__pycache__`, bytecode, virtualenvs, packaging metadata, pytest/mypy/ruff caches, `.env`. |
| `node` | `node_modules`, build output (`.next`, `dist`), logs, coverage, `.env`. |
| `go` | Go binaries, `*.test`, coverage output, `vendor/`, `go.work`, `bin/`. |
| `rust` | Cargo `target/`, `*.pdb`, coverage reports, editor metadata. |
| `java` | `*.class`, archives, Maven `target/`, Gradle `.gradle/` and `build/`, IDE files. |
| `c` | Object files, static/shared libraries, executables, `build/`, `bin/`, `obj/`. |
| `cpp` | C++ objects, CMake build trees, shared/static libraries, executables. |
| `macos` | `.DS_Store`, `._*`, Spotlight/Trash metadata, volume droppings. |
| `windows` | `Thumbs.db`, `Desktop.ini`, installer packages, shortcuts, `$RECYCLE.BIN`. |
| `linux` | Editor swap files, `*~` backups, core dumps, `.Trash-*`, `lost+found/`. |
| `vscode` | `.vscode` local state while keeping shared `settings.json`, `launch.json`, `tasks.json`. |
| `jetbrains` | `.idea/`, `*.iml`, `*.ipr`, `*.iws`, IDE build output. |
| `git` | Merge/rebase leftovers (`*.orig`, `*.rej`), patches, local git config. |
| `docker` | Build tarballs, compose overrides, container env files, local volumes, logs. |
| `terraform` | `.terraform/`, `*.tfstate`, `crash.log`, `*.tfvars`, override files, CLI config. |

Templates are maintained in `src/gitignore_gen/templates.py` as a plain dictionary of `Template` records, so adding your own is a one-line registry change.

## Development

```bash
git clone https://github.com/DelmarMG91/gitignore-gen.git
cd gitignore-gen
python -m pip install -e ".[dev]"
python -m pytest -q
```

Run the CLI without installing:

```bash
python -m gitignore_gen --help        # with src on PYTHONPATH
```

On Windows PowerShell:

```powershell
$env:PYTHONPATH = "src"
python -m gitignore_gen list
```

Project layout:

```text
src/gitignore_gen/
  __init__.py     version metadata
  __main__.py     python -m entry point
  cli.py          argparse command implementations
  templates.py    curated template registry
  detector.py     project marker detection
  writer.py       merge, de-duplicate, append-safe writing
tests/            pytest suite (templates, detector, writer, CLI)
```
